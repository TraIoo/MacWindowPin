# 置顶 · MacWindowPin

一个原生中文 macOS 菜单栏工具：把一个窗口的实时画面显示在悬浮层，方便边看边操作其他窗口。

**这是窗口镜像，不会给原窗口赋予系统级的永久置顶属性。** 点击镜像的第一下用于切回原窗口，第二下起正常操作；原窗口失焦后恢复镜像。

[下载与版本记录](https://github.com/TraIoo/MacWindowPin/releases) · [更新日志](CHANGELOG.md) · [验证范围](VALIDATION.md)

## 运行要求

- macOS 14.0 及以上；当前提供 Apple Silicon（arm64）构建。
- 已验证环境为 M1 / macOS 14.8.8。其他 macOS 版本和第三方应用仍需实际验证；未提供 Intel 构建。
- 使用时需要为实际打开的「置顶」APP 允许**辅助功能**和**屏幕录制**。
- 分发包使用 ad-hoc 本地签名，**未做 Apple 公证**，不是 App Store 分发版本。系统可能阻止首次打开，请通过系统提供的安全设置操作；无需关闭 SIP。

## 开始使用

1. 从 Releases 下载 `置顶-0.1.1-macOS-arm64.zip`，解压，将 APP 放在固定位置后打开。菜单栏出现图钉，无 Dock 图标。
2. 点击图钉 →「设置与权限」，阅读用途后允许两项权限。若系统要求重新启动，退出工具后再次打开。
3. 回到目标窗口按 **Control + Option + P**。也可从菜单选择「选择窗口…」，悬停查看轮廓，单击确认，按 Esc 取消。
4. 同时只支持一个窗口，选择新窗口会替换旧窗口。
5. 点击镜像的**第一下只负责进入原窗口**，不会把这次点击转发给原窗口；后续点击、键盘输入由原窗口处理。切换到其他普通窗口后恢复镜像。
6. 在当前目标窗口再次按快捷键，或在菜单中选择「取消置顶」。快捷键可在设置中修改；冲突时保留原快捷键。

重编译、替换或移动 APP 后，系统可能要求重新授权。请确认隐私列表中的条目对应当前 APP；终端或测试程序获得授权，不等于分发 APP 已获得授权。工具不会自动重置权限数据库。

## 画面和权限

使用 ScreenCaptureKit 仅捕捉选中的窗口，最高 **15 fps**；不捕捉音频，不保存图片或视频，不上传画面。系统的「正在共享」提示表示本机实时窗口捕捉，不代表网络共享。

进入原窗口交互时停止捕捉，隐藏镜像，同时保留每秒一次的状态检查以判断失焦和窗口失效。未置顶时没有捕捉流、窗口状态轮询或 AX 观察者。仅移动窗口时移动镜像面板；尺寸或显示比例变化时重建捕捉，保留原生像素比例。

## 使用边界

- 面向能由公开辅助功能接口准确识别和聚焦的普通桌面窗口。第三方应用的菜单、输入法、附属窗口等仍需逐应用验证。
- 同标题、同位置、同尺寸的多个窗口可能无法可靠区分；此时拒绝置顶，可先挪开其中一个再试。
- 原窗口关闭、最小化，源应用隐藏或退出，以及桌面 / 原生全屏、睡眠或会话切换时会取消置顶。默认不跨 Space 或原生全屏保持镜像。
- 受保护内容或特殊窗口可能无法捕捉。部分应用缺少辅助功能通知时，状态更新最多可能延迟约一秒。
- 首击交接使用公开的应用激活和 AXRaise，确认准确窗口获得焦点后再隐藏镜像；失败会取消并提示。
- 不模拟转发鼠标，不移动光标，不注入进程，不使用私有 API，不修改 SIP。

真实鼠标拾取、中文输入法候选翻页、物理多屏 DPI 切换、实际睡眠唤醒和权限撤销等仍有未完成的人工验收项，详见 [VALIDATION.md](VALIDATION.md)。

## 从源码构建

需要 Apple Command Line Tools、Swift 编译器、Python 3，以及 macOS 自带的 zsh 和签名工具。已使用 Swift 6.0.3 验证，按 Swift 5 语言兼容模式编译；无需第三方依赖或构建时联网。

在源码根目录运行：

```sh
zsh Scripts/build.sh
open 'dist/置顶-0.1.1.app'
```

脚本默认生成 arm64、最低 macOS 14.0 的 APP，并使用 ad-hoc 签名。若已有可用签名身份，可通过 `WINDOWPIN_SIGN_IDENTITY` 指定；脚本本身不执行公证。

构建缓存和调试符号留在 `build/`，APP 位于 `dist/`。工具链若含重复的 SwiftBridging 模块声明，脚本会自动生成本地编译器 VFS overlay，不修改系统 SDK。

如需打包自己构建的 APP：

```sh
ditto -c -k --keepParent 'dist/置顶-0.1.1.app' 'dist/置顶-0.1.1-macOS-arm64.zip'
```

## 开发验证

```sh
# 身份匹配与基础边界测试
zsh Scripts/test.sh

# 使用两个临时窗口程序进行真实捕捉与焦点转换测试
zsh Scripts/integration-test.sh
```

基础测试构建独立的 `build/置顶测试.app`，覆盖身份匹配、快捷键冲突、完整点击消费、异步串行、枚举截止和清理；不代表分发 APP 的权限、实机捕捉或第三方兼容性已通过。

集成测试会打开自己的临时窗口、切换焦点，并短暂进入自己的原生全屏，请在不需要操作其他窗口时运行。它需要为实际执行测试的程序授予权限；缺权限时记录 `BLOCKED`，不算通过。结果位于脚本打印的临时目录中的 `integration-results.log`。如测试中断或受阻，手动关闭临时测试窗口即可。测试只操作临时内容。

仅需构建测试 APP 时：

```sh
WINDOWPIN_TESTING=1 zsh Scripts/build.sh
```

发布 APP 不含自测、集成测试和性能测试入口；保留只读诊断入口 `--diagnose`。自测和诊断可能输出系统、进程及窗口信息，分享日志前请检查内容。测试宿主的授权状态不能替代最终 APP 的验证。

## 源码结构

| 路径 | 用途 |
| --- | --- |
| `Sources/Accessibility.swift`、`WindowIdentity.swift` | 公开 AX 接口、窗口身份与唯一匹配 |
| `Sources/Capture.swift`、`PinController.swift` | 捕捉、镜像、首击交接、串行启停与清理 |
| `Sources/WindowPicker.swift` | 窗口拾取与轮廓 |
| `Sources/HotKey.swift`、`Settings.swift`、`AppDelegate.swift` | 快捷键、设置和菜单栏 |
| `Sources/*Tests.swift`、`Tests/` | 显式触发的测试和临时窗口程序 |
| `Scripts/`、`Resources/` | 构建与验证脚本、APP 元数据 |

本仓库为独立实现。目前尚未指定许可证。
